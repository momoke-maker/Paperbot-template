# Paperbot 🎧📄

בכל בוקר מגיע אליכם לטלגרם פודקאסט קצר בעברית (12–16 דקות) על מאמר מחקר אחד מהתחום שלכם: שני מגישים עוברים על התיאוריה, השיטה, מה בדיוק מדדו ואיך, התוצאות והמשמעות שלהן, והדיון. בנוסף, אפשר לשלוח לבוט בכל רגע PDF או קישור למאמר, ותוך כמה דקות מגיע פרק עליו.

הכל פרטי: ריפו פרטי שלכם ב-GitHub, בוט פרטי בטלגרם, ומפתחות שרק אתם מחזיקים.

## איך זה עובד

| חלק | מה הוא עושה | עלות |
|---|---|---|
| **Claude** (משימה מתוזמנת) | כל בוקר בוחר מאמר, קורא אותו במלואו וכותב תסריט | חלק מהמנוי ל-Claude |
| **Undermind** | מנוע חיפוש אקדמי: מוצא את המאמר ומאפשר לקרוא את ה-PDF המלא | חינם דרך האוניברסיטה (ראו שלב 7) |
| **GitHub** | שומר את הכל, ומריץ את הפקת הקול והשליחה | חינם |
| **Gemini** (גוגל) | הופך את התסריט לקול של שני מגישים, וכותב פרקים לפי בקשה | חינם (מכסה חינמית) |
| **טלגרם** | הבוט הפרטי שבו הפרקים מגיעים | חינם |
| **Google Apps Script** | בודק כל דקה אם שלחתם לבוט PDF או קישור | חינם |

**מה צריך:** מנוי ל-Claude, חשבון GitHub, חשבון גוגל, טלגרם, ומייל של האוניברסיטה. ההקמה לוקחת בערך 20–30 דקות, פעם אחת.

> 💡 הכי פשוט לעשות את ההקמה יחד עם Claude: פתחו צ'אט, צרפו את הקישור לריפו, ובקשו ממנו ללוות אתכם צעד אחר צעד לפי ה-README.

## שלב 1: יוצרים עותק משלכם
1. בראש העמוד הזה לוחצים **Use this template** ← **Create a new repository**.
2. נותנים שם (למשל `paperbot`) ומסמנים **Private**. חשוב: הריפו יכיל את המאמרים והפרקים שלכם.
3. **Create repository**.

## שלב 2: בוט בטלגרם
1. בטלגרם מחפשים **@BotFather** (עם וי כחול) ושולחים `/newbot`.
2. נותנים שם לבוט, ושם משתמש שנגמר ב-`bot`.
3. מקבלים **טוקן** (נראה כמו `1234567890:ABC...`). שומרים אותו בצד. זו סיסמה, לא משתפים אותה.
4. נכנסים לבוט החדש ושולחים לו `/start`.

## שלב 3: מפתח Gemini
נכנסים ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) ← **Create API key** ← מעתיקים.

## שלב 4: שומרים את המפתחות בכספת של הריפו
בריפו שלכם: **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**. יוצרים שניים:
- `GEMINI_API_KEY`: המפתח משלב 3
- `TELEGRAM_BOT_TOKEN`: הטוקן משלב 2

## שלב 5: מספרים לבוט מי אתם
עורכים ישירות ב-GitHub (פותחים את הקובץ ← אייקון העיפרון ← **Commit changes**):
- **`config/listener.md`**: השם שלכם (באיות עברי), איך לפנות אליכם (זכר/נקבה), התחום ומה אתם חוקרים.
- **`config/topics.md`**: הנושאים שמעניינים אתכם. יש שם גם רשימת דירוג של כתבי עת (קודם הנחשבים ביותר, ורק אם אין, יורדים דרגה). אפשר להתאים אותה לתחום שלכם.
- **`config/library.md`** (לא חובה): מאמרים שאתם כבר מכירים, כדי שלא ייבחרו.

## שלב 6: פרק ניסיון
1. ודאו ששלחתם `/start` לבוט (שלב 2).
2. בריפו: **Actions** ← בצד שמאל **Make episode** ← **Run workflow** ← **Run workflow**.
3. אחרי 2–3 דקות אמור להגיע לטלגרם פרק ניסיון קצר. 🎉
4. בריפו נוצר קובץ `config/chat_id.txt` עם מספר הצ'אט שלכם. תצטרכו אותו בשלב 9.

אם משהו נכשל: לוחצים על הריצה האדומה ב-Actions וקוראים את השגיאה (או מעתיקים אותה ל-Claude).

## שלב 7: Undermind ⭐
1. נרשמים ל-[app.undermind.ai](https://app.undermind.ai) **עם המייל של האוניברסיטה** (למשל `@post.runi.ac.il`). זה חשוב: באוניברסיטת רייכמן ההרשמה עם המייל האוניברסיטאי נותנת מנוי **Pro בחינם** דרך האוניברסיטה (בחשבון יופיע "Access provided by Reichman University"). באוניברסיטאות אחרות כדאי לבדוק אם יש הסדר דומה.
2. יוצרים workspace חדש, למשל `Paperbot`.
3. מעתיקים את המזהה שלו מהכתובת: `app.undermind.ai/projects/`**`<המזהה>`**.
4. מחברים את Undermind ל-Claude: בהגדרות של Claude, תחת Connectors, מוסיפים את Undermind ומתחברים עם אותו חשבון.

## שלב 8: המשימה היומית ב-Claude
1. ודאו ש-GitHub מחובר ל-Claude (גם זה דרך Connectors), כדי ש-Claude יוכל לכתוב לריפו שלכם.
2. פותחים את הקובץ **`DAILY_TASK_PROMPT.md`** ומחליפים בו את שני הסימונים:
   `<<OWNER/REPO>>` (למשל `noa-cohen/paperbot`) ו-`<<UNDERMIND_WORKSPACE_ID>>` (משלב 7).
3. פותחים צ'אט חדש ב-Claude וכותבים:
   > צור לי משימה מתוזמנת יומית בשעה 07:13 לפי שעון ישראל, עם הפרומפט הבא:
   
   ומדביקים את הפרומפט (כל מה שמתחת לקו בקובץ).
4. מחר בבוקר, בסביבות 07:30–07:45, יגיע הפרק היומי הראשון.

## שלב 9: שליחת PDF או קישור לבוט
זה החלק שמאפשר לשלוח לבוט מאמר ולקבל עליו פרק, כולל מאמרים בתשלום שהורדתם דרך האוניברסיטה.

**א. טוקן GitHub מוגבל**
1. [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new)
2. **Name:** `paperbot-relay`, **Expiration:** שנה.
3. **Repository access** ← **Only select repositories** ← הריפו שלכם.
4. **Permissions** ← **Contents** ← **Read and write**.
5. **Generate token** ← מעתיקים.

**ב. Google Apps Script**
1. [script.google.com](https://script.google.com) ← **New project** ← משנים את השם ל-`paperbot-relay`.
2. מוחקים את מה שבעורך ומדביקים את התוכן של **`relay/apps_script.gs`** (בקובץ ב-GitHub יש כפתור **Copy raw file**, וכך לא נחתך כלום).
3. בשורה `const REPO = ...` מחליפים לשם המשתמש והריפו שלכם, למשל `'noa-cohen/paperbot'`. שומרים (💾).
4. גלגל השיניים (**Project Settings**) ← **Script properties** ← מוסיפים שלושה:
   - `TELEGRAM_BOT_TOKEN`: הטוקן מהבוט
   - `GH_TOKEN`: הטוקן משלב 9א
   - `CHAT_ID`: המספר מ-`config/chat_id.txt` (שלב 6)
5. חוזרים לעורך, בוחרים למעלה את הפונקציה **`setup`** ← **Run**.
6. גוגל יבקש הרשאות: **Review permissions** ← בוחרים חשבון ← "Google hasn't verified this app" זה תקין (זה סקריפט שאתם כתבתם לעצמכם) ← **Advanced** ← **Go to paperbot-relay** ← מסמנים הכל ← **Continue**.

ההרשאות הן רק להתחבר לטלגרם ול-GitHub ולרוץ כל דקה. אין גישה למייל, לדרייב או לשום דבר אחר.

**בדיקה:** שלחו לבוט PDF של מאמר. תוך דקה הוא יענה "קיבלתי", ותוך 5–10 דקות יגיע הפרק.

## שימוש יומיומי
- **פרק יומי:** מגיע לבד כל בוקר.
- **PDF או קישור:** שולחים לבוט ← פרק תוך דקות. קישור עובד רק למאמרים פתוחים; למאמר בתשלום, מורידים דרך האוניברסיטה ושולחים את הקובץ.
- **הערות:** עונים (Reply) על הודעת הפרק וכותבים מה שרוצים. ההערות נשארות בצ'אט והבוט מתעלם מהן.
- **שינוי הסגנון:** כל ההנחיות לכתיבת הפרקים נמצאות ב-`config/episode_guidelines.md`. אפשר לערוך אותן ישירות, או לבקש מ-Claude.

## פרטיות ואבטחה
- המפתחות נשמרים רק בכספת של GitHub ובהגדרות של הסקריפט שלכם. הם לא כתובים באף קובץ.
- הבוט שולח פרקים רק למספר הצ'אט שלכם.
- לעולם אל תכניסו לשום מקום את פרטי ההתחברות שלכם לאוניברסיטה. מאמרים בתשלום מורידים בעצמכם ושולחים לבוט.
