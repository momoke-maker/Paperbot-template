# Paperbot 🎧📄

בכל בוקר מגיע אליכם לטלגרם פודקאסט קצר (12–16 דקות, בעברית או באנגלית) על מאמר מחקר אחד מהתחום שלכם: שני מגישים עוברים על התיאוריה, השיטה, מה בדיוק מדדו ואיך, התוצאות והמשמעות שלהן, והדיון.
בנוסף, אפשר לשלוח לבוט בכל רגע PDF או קישור למאמר, ותוך כמה דקות מגיע פרק עליו.

הכל פרטי: ריפו פרטי שלכם ב-GitHub, בוט פרטי בטלגרם, ומפתחות שרק אתם מחזיקים.

## מה צריך
מנוי ל-Claude, חשבון GitHub, חשבון גוגל, טלגרם, ומייל של האוניברסיטה. ההקמה לוקחת בערך חצי שעה, פעם אחת, וכולה חינמית (חוץ מהמנוי ל-Claude).

## ההקמה: Claude עושה את רוב העבודה

1. בראש העמוד הזה: **Use this template** ← **Create a new repository**. נותנים שם (למשל `paperbot`), מסמנים **Private** ← **Create repository**.
2. בהגדרות של Claude, תחת **Connectors**, מחברים את **GitHub**.
3. פותחים צ'אט חדש ב-Claude וכותבים:
   > תקים לי את Paperbot. הריפו שלי: `<שם-המשתמש>/<שם-הריפו>`

Claude יקרא את הוראות ההקמה שבפרויקט, ישאל אתכם על השפה, התחום והמחקר שלכם, ימלא את ההגדרות, ידריך אתכם צעד אחר צעד בכל מה שדורש את החשבונות שלכם, יבדוק שכל שלב עובד, ויגדיר את המשימה היומית.

### מה רק אתם יכולים לעשות (Claude ידריך אתכם בכל אחד)
- **בוט בטלגרם:** דרך @BotFather (עם וי כחול), כולל שליחת `/start` לבוט החדש.
- **מפתח Gemini:** ב-[aistudio.google.com/apikey](https://aistudio.google.com/apikey).
- **שמירת שני המפתחות בכספת של הריפו:** Settings ← Secrets and variables ← Actions.
- **Undermind:** הרשמה ל-[app.undermind.ai](https://app.undermind.ai) **עם המייל של האוניברסיטה**. ברייכמן זה נותן מנוי **Pro בחינם** דרך האוניברסיטה. אחרי ההרשמה מחברים את Undermind ל-Claude (Connectors), ואת השאר Claude עושה.
- **הממסר בגוגל:** יוצרים פרויקט ב-Google Apps Script, מדביקים קוד ש-Claude כבר הכין עבורכם, ומאשרים הרשאות.

> 🔐 מפתחות, טוקנים וסיסמאות לא שולחים ל-Claude בצ'אט. הם נכנסים רק לכספת של GitHub ולהגדרות של הסקריפט בגוגל, ואתם מכניסים אותם בעצמכם.

## שימוש יומיומי
- **פרק יומי:** מגיע לבד כל בוקר.
- **PDF או קישור:** שולחים לבוט ← פרק תוך דקות. קישור עובד רק למאמרים פתוחים; למאמר בתשלום, מורידים דרך האוניברסיטה ושולחים את הקובץ.
- **הערות:** עונים (Reply) על הודעת הפרק. ההערות נשארות בצ'אט והבוט מתעלם מהן.
- **שינויים:** סגנון, אורך, נושאים או דירוג כתבי העת. פשוט מבקשים מ-Claude, והוא מעדכן את הקבצים ב-`config/`.

## פרטיות ואבטחה
- המפתחות נשמרים רק בכספת של GitHub ובהגדרות של הסקריפט שלכם, לא באף קובץ.
- הבוט שולח פרקים רק למספר הצ'אט שלכם.
- לעולם אל תכניסו לשום מקום את פרטי ההתחברות שלכם לאוניברסיטה.
- הטוקן של GitHub בתוקף לשנה. כשיפוג, הבוט ישלח לכם הודעה, ו-Claude יעזור לחדש אותו.
